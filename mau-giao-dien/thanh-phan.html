Trang chủ / Mẫu thành phần giao diện

Mẫu thành phần giao diện

Trang nội bộ cho nhóm: mỗi mục có bản hiển thị và đoạn code để sao chép. Dùng đúng class có sẵn trong css/common.css và css/style.css để mọi trang trông đồng bộ. Trang admin dùng thêm css/admin.css (xem admin/index.html).

1. Nút bấm

Dùng được cho thẻ <a> và <input type="submit">.

Nút chính Nút viền Đặt hàng Xóa Nút nhỏ 
<a class="btn" href="#">Nút chính</a>
<a class="btn btn-outline" href="#">Nút viền</a>
<a class="btn btn-gold" href="#">Đặt hàng</a>
<a class="btn btn-danger" href="#">Xóa</a>
<a class="btn btn-small" href="#">Nút nhỏ</a>
<input type="submit" class="btn" value="Gửi form" />

2. Form trong khung (đăng nhập, đăng ký)

Khung .form-box rộng 400px, ô nhập dùng class w-full.

6. Phân trang

Mỗi trang là 1 file html riêng (nhan.html, nhan-2.html...). Trang hiện tại dùng span.current.

« 1 2 » 
<div class="pagination">
    <span class="disabled">&laquo;</span>
    <span class="current">1</span>
    <a href="#">2</a>
    <a href="#">&raquo;</a>
</div>
